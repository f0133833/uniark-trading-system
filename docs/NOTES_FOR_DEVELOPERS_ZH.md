## 一、缠论代码化的真正难点

试图把缠论写成代码的人，几乎都会撞上同一堵墙:

- K 线包含关系合并(向上 / 向下方向规则)
- 分型(顶分型 / 底分型)的识别和有效性判定
- 笔的"至少 N 根 K 线"和包含关系处理后怎么数
- 线段的特征序列、缺口处理、破坏的破坏

这些规则在原文里都是用例子讲的，落到代码里立刻面临十几个 if-else 边界。
缠论社区内部对每一条规则都存在版本分歧。一个老老实实想"严格按缠论
实现"的开发者，最终会写出一套不知所云，逻辑混乱的代码，或者干脆放弃。

**这堵墙的根源，不是开发者不够努力，而是这套规则**本身**就承担了一个
不可能任务**——试图从 K 线层一砖一瓦垒起来，在没有外部参考的情况下，
单凭价格序列结构判断"什么是一段真正的走势"。这个任务在数学上是欠定的:
任何裁决规则都依赖未明说的约定(合并方向、最小长度、缺口归属等)，
而这些约定并不比"用 MACD hist 翻号定义段"更基础——它们只是没被
明确标记为约定。

## 二、绕过这堵墙的核心想法

本项目的处理方式可以概括成一句话:

> **把"一段走势"作为未定义原语保留在理论层，
> 用 MACD hist 的符号在工程层兜底它的定义。**

具体做法:

1. **理论文档**(`THEORY_ZH.md`)从"转折点"和"一段走势"开始构造，
   不试图从更底层(K 线 / 分型)推导它们。这是**有意的留白**。
2. **代码实现**(`divergence.py`)把"hist 翻号那一刻"定义为段的边界，
   填补这个留白。

这一步换得很划算，但也是真实的取舍:

**换到的好处:**

- 段变成了可机械确定的对象，零歧义，代码不需要任何主观判断
- 和"力度 = Σ|hist|"的定义完美自洽——既然用 hist 面积度量力度，
  那么用 hist 同号区间定义段，理论的两块严丝合缝
- 绕开了缠论里最难也最招争议的 K 线 / 分型 / 笔 / 线段层

**付出的代价:**

- 动量先于价格转向。价格的真实顶 / 底常落在 hist 已翻号之后若干根
  K 线上，导致极值落在"颜色错位"的反向段里。`find_missed_extremes`
  补检函数的存在正是为了处理这种结构性漏检。
- MACD 参数 (12， 26， 9) 成了体系的一个隐含输入。理论形式上不提它，
  但段的具体位置依赖它。

**为什么这个取舍是可接受的:** 缠论的 K 线 / 分型 / 笔 / 线段那一层
**也**包含大量未明说的经验约定，只是它们装扮成"基础规则"的样子。
本项目的做法把这种约定显性化——明确告诉你"这里有一个工程接口，
理论留白由它兜底"——反而让整个体系的认识论地位更清楚:**哪些是公理，
哪些是为了让公理可计算而引入的工程接口**。

## 三、噪声处理:用递归代替过滤

代码化任何这类理论都会遇到的实际问题:**短反向段(几根 K 线的小回调)
要不要算独立的段?**

传统思路是设阈值过滤:小于 N 根 K 线的反向段算"噪声"，并入相邻段。
这就是本项目代码里 `min_bars` 参数的原始用途——但**这个参数在实际配置
中是 0，也就是默认关闭**。原因是项目最终选择了哲学上更干净的方案:

> **不过滤噪声，而是用层级递归吸收它。**

具体说，三段背离不止在原始段序列 S1， S2， S3 上检测，还在它们的复合上
继续检测:

- 基础层 L1:S1， S2， S3 (基础三段结构)
- 复合段 P1 = S1 + S2 + S3 (sign = S1.sign，area = S1.area + S3.area)
- 第 2 层 L2:P1， S4， S5
- 第 3 层 L3:P2， S6， S7
- ...递归向上

**这一设计为什么更优雅:**

- "噪声过滤"预设了一个外部判据("多短的段算噪声")，用它把数据
  预处理一遍。
- "递归扩展"根本不预设"噪声"这个概念。所有 hist 翻号都是合法的段。
  要不要把某个反向段看成"真实反转"还是"中继扰动"，由更高层级的
  结构判定本身回答。
- 短反向段不需要被消除，它们只是在某个层级上还不重要而已。
- 力度公式 P.area = S1.area + S3.area 把反向段直接排除在外。一个
  微小的 S2 进入 P1、或被预过滤合并掉，最后 P1 的力度数值是一样的。
  **力度公式本身已经免疫于反向段大小，再加一道 min_bars 合并其实是冗余的。**

**这是真正可迁移的设计模式。** 任何做缠论代码化、或类似框架代码化的人，
都会面对"小回调算不算独立的笔"这个问题。把"用层级递归吸收"代替
"用阈值过滤"的思路拿走，可以省掉一大堆按品种、按周期调参的痛苦。

**一点附加观察:** 缠论原文的"不同级别联立"用的是不同时间周期
(5 分钟 vs 30 分钟 vs 日线)，每个级别独立分析再做对照。本项目的
L1 / L2 / L3 是**同一份数据、同一组段序列上的递归层级**。这是两个
正交的多尺度维度:一个是 K 线粒度的换挡，一个是结构组合的递归。
项目的"金字塔钻取"用前者，层级背离用后者。

## 四、MACD 作为理论组件:三层验证

把 MACD 写进一个号称"公理化"的理论，需要先回答一个问题:
**MACD 是基于经验的启发式，还是基于真实价格的算法?**

这个区分很关键。RSI 的 30 / 70、布林带的 ±2σ 这类指标，核心信号
是约定阈值;把它们写进公理就是在体系里塞进未声明的经验前提。
MACD 不一样，值得分三层看:

**第一层:算法本身。** MACD 是纯算术，没有任何拟合、学习、阈值判定:

```
MACD(t)   = EMA(price， 12)(t) - EMA(price， 26)(t)
Signal(t) = EMA(MACD， 9)(t)
hist(t)   = MACD(t) - Signal(t)
```

给定价格序列，MACD 完全确定。**这一层是基于价格的数学函数，
不是经验启发式。** ✓

**第二层:结构解释。** EMA 是低通滤波器，所以:

- `EMA(12) - EMA(26)` 是一个**带通滤波器**——放大处于"中等周期"的
  价格波动，压制噪声和长期趋势。这等价于价格在某个频段上的动量。
- `hist = MACD - EMA(MACD， 9)` 是这个动量信号自身变化率的平滑近似。

接起来:**hist(t) ≈ 价格的二阶导数在某个频段上的平滑版本。**
它的符号告诉你价格动量在加速还是减速;翻号那一刻是动量拐点。

这层解释没有任何经验成分——是带通滤波加微分这两个标准信号处理操作
的复合，每一步都有明确数学含义。所以"hist 翻号"作为段的分界点，
不是有人**规定**它有意义，而是它**结构上**就标记了动量拐点。✓

**第三层:参数 (12， 26， 9)。** 这三个数字是 Gerald Appel 在 1970 年代
根据美股观察选的，不是从第一性原理推导出来的。换成 (10， 20， 7) 或
(15， 30， 10)，所有上面的数学性质都成立(仍是带通+微分)，只是
"中等周期"具体落在哪儿会变。**这一层是经验的。** ✗

**结论:**

- 算法本身:基于价格，非经验。✓
- 结构解释(hist 翻号 = 动量拐点):数学性质，参数无关，非经验。✓
- 具体在哪一根 K 线翻号:参数依赖，经验。✗

把 MACD 数值纳入理论是**正当的**——但理论的断言要落在**结构性事实**
层面("段存在"、"力度衰竭"、"背离成立")，不能落在**精确时间点**
层面("在某月某日 14:30 转折")。

这一点和第三节的递归扩展配合得非常好:**理论只承认参数无关的结构事实，
参数敏感的细节交给层级递归自动消化。** 短段在 L1 层有自己的位置，
到了 L2 层自然被吸收进复合段——这个机制让更高级别的判断对 MACD
参数选择鲁棒。

**这套三层验证可以复用。** 想把其他工具(成交量、均线、ATR)纳入
类似的公理化框架时，问自己同样的三个问题:

1. 算法本身是不是价格的纯函数?
2. 结构性陈述(信号的语义)是不是参数无关的?
3. 参数敏感性影响的是真值，还是只是时间精度?

只要 (1)(2) 答"是"，而 (3) 影响的只是时间精度，这个工具就可以
合法地进入公理体系——前提是断言要落在结构层而非时点层。

## 五、和缠论的对照

为了让读者定位本项目相对于缠论的位置，做一个表格化的对照:

| 维度 | 缠论原文 | 本项目 |
|------|---------|--------|
| 一段走势的定义 | 从 K 线 → 分型 → 笔 → 线段一层层构造 | 留白，由 MACD hist 翻号兜底 |
| 中枢 / 重叠区间 | 三段重叠 + 一旦形成不变 | 同左，本项目术语叫"盘整区间" |
| 趋势的递归构造 | 多个中枢 + 抬高 / 下降 | 同左 |
| 力度度量 | MACD 柱面积 | 同左 |
| 背驰 / 背离 | 趋势背驰 + 盘整背驰 | 趋势背离 + 三段背离，加 L≥2 分层 |
| 买卖点 | 三类 | 两类(对应一类和三类)，缺二类 |
| 多级别分析 | 不同 K 线周期联立 | 同一周期内的 L1/L2/L3 递归 **+** 不同周期金字塔钻取 |
| 短反向段处理 | 通过笔 / 线段的有效性规则隐式处理 | 不处理，由层级递归自动吸收 |
| 转折确认 | 笔 / 线段的破坏规则 | "上涨破坏 / 下跌破坏"的精确化定义 |
| 风格 | 散文 + 例子 | 公理 + 演绎 |
| 可计算性 | 取决于实现者对争议规则的取舍 | 直接可写代码 |

如果读这个表，你能感受到:**核心骨架与缠论有相似度，被简化掉的是
最难代码化的那一层，被加强的是形式化的严谨度和可证伪性。**

## 六、代码化缠论时容易踩的坑

把这次讨论里提炼的设计模式总结成几条具体可操作的提示:

**(1) 不要试图严格实现笔 / 线段的所有规则。** 缠论社区内部对这些
规则就有版本分歧，没有"唯一正确"的实现。选择一个**数学上无歧义的
替代定义**(本项目用 MACD hist 翻号，你也可以用别的)填补这个留白，
然后把这个替代定义显性化、文档化。

**(2) 短反向段不要预过滤。** 用递归扩展自动吸收。这不仅哲学上更
干净，工程上也省掉了"按品种、按周期调阈值"的反复调参痛苦。

**(3) 力度公式要免疫于反向段大小。** P.area = Σ(同向段.area) 而
不计入反向段，这样递归扩展不会因为某个 S2 太短或太长而扭曲数值。

**(4) 区分结构性陈述和时点陈述。** "存在背离"是结构陈述，参数无关;
"背离精确发生在 t = T"是时点陈述，参数依赖。把交易决策建立在
结构陈述上，不要建立在时点陈述上。

**(5) 动量先于价格，要补极值。** 价格真实顶 / 底常落在 hist 翻号之后，
导致标准的三段结构扫描漏掉极值。需要单独一个补检规则处理这种情况
(见 `find_missed_extremes`)，不要相信"标准检测应该能覆盖所有情况"。

**(6) "暂定信号"要明确标记。** 当 S_last 正好延伸到数据末端时，
ratio 是个快照，后面还会变。这种情况要在 UI 上明确视觉区分
(本项目用蓝色 + `?` 后缀)，不要让用户误以为是已确认信号。

**(7) "屏障"和"扩展"要分清。** 当一个同向结构在形成过程中跨过另一
个已触发的反向信号时，这个同向结构在结构上是无效的——它把"反转之前"
和"反转之后"错误合并了。具体语义见 `divergence.py` 顶部的"反向屏障
规则"段落，这是项目里最不平凡的一段。

## 七、本文不解决的问题

为避免给读者不切实际的期待，坦白讲清楚:

**代码化缠论的"难"，有一半技术性，另一半经验性。** 本文谈的是
前一半——理论 / 工程接口、噪声处理、指标合法性。但实战决策还需要
另一半:

- 什么级别的中枢震荡值得交易?
- 第二类买卖点的回踩深度多少算合理?
- 哪些品种适合用本框架?哪些不适合?
- 仓位管理怎么和结构信号配合?

这些问题本质上需要历史数据上的统计观察，不是公理化能直接给出答案的。
本项目的可视化工具可以**辅助**你做这些观察，但**不替代**这些观察。

任何想用这个框架做实盘决策的读者，本项目 README 已经说过:

- 自行做统计验证(含真实滑点、手续费、税费)
- 与买入持有等被动基准对比
- 认识到"图上漂亮"不等于"实盘赚钱"
